# GreenLoop Frontend (HTML, CSS and JavaScript)

- `index.html`: public homepage and collection request form.
- `track.html`: customer collection tracking page.
- `css/style.css`: visual design and responsive styling.
- `js/app.js`: form handling, browser GPS capture and PHP API connection.
- `js/track.js`: tracking lookup and live map refresh.

The frontend calls the PHP backend one directory above: `../api.php`. Keep the `frontend` folder inside the main `wastewise_project` folder and run the project through XAMPP/Apache; do not open the HTML files directly with `file://`.
